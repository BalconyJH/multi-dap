# Security Policy

## Supported versions

No public release has been issued yet. Security fixes are currently applied to
the default development branch only. This section will be replaced with a
version support table when the first release is published.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or security-advisory feature for
this repository. Do not open a public issue for vulnerabilities, leaked
credentials, target connection details, or raw device output.

Include the affected revision, platform, impact, reproduction conditions, and
whether the report involves a real target. Remove control tokens, private
paths, target-server arguments, firmware contents, and hardware identifiers.

The project security model and release gates are documented in
[docs/security.md](docs/security.md).
